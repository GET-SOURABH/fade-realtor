# Regan Irish Style Static Website Recreation

A single-page luxury real-estate website recreation built with plain HTML, CSS and JavaScript.

## Run

Open `index.html` directly in a browser, or run a tiny local server:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Files

- `index.html` — page structure/content
- `styles.css` — responsive styling and layout
- `script.js` — hero slider, mobile menu, listings controls, testimonials, FAQ and reveal animations

## Notes

The page references public image URLs from the inspiration site so the project stays lightweight. Replace those URLs with your client's licensed images before production deployment.
